# Developh

A design and development studio in Lisbon. We build websites, online stores, web apps and brands for restaurants,
clinics, tourism and product companies, and we publish the tools we use to work with AI agents.

**Work:** [developh.co/projects](https://www.developh.co/projects) · **Contact:** hello@developh.co

## Open source

| | What it does | Install |
|---|---|---|
| [**reap**](https://github.com/Developh/reap) | Kills the zombie processes AI coding agents leave behind on macOS | `brew install developh/tap/reap` |
| [**resolve-cut**](https://github.com/Developh/resolve-cut) | Claude Code edits, renders and checks your videos in DaVinci Resolve | `npx skills add developh/resolve-cut` |
| [**skills**](https://github.com/Developh/skills) | Free website audits (speed, SEO, accessibility) for any agent, over our MCP server | `npx skills add developh/skills` |

## For agents
